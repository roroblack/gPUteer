  94) 다른 Coordinator 앞으로 온 신고는 세션 거부(kind=protocol), DB 불변

  97) 구현하지 않은 lane 조합(multi-agent)은 조용히 무시하지 않고 거부한다

5. 순서를 어떻게 값으로 드러냈는가
------------------------------------
"관문이 bind 보다 먼저인가" 는 `READY` 부재로는 증명되지 않는다 —
"bind 는 했는데 READY 전에 죽었다" 와 구분이 안 된다.

  기법 A (점유 포트)
    이미 다른 listener 가 잡은 포트를 준다.
      관문이 먼저면  -> 구성/lane 오류로 끝난다
      관문이 나중이면 -> "bind 실패" 로 끝난다
    두 오류 문구가 다르므로 순서가 값이 된다.

  기법 B (테스트가 listener 를 소유)
    테스트가 자기 listener 를 열고 그 주소를 Agent 에게 준다.
    끝난 뒤 accept() 가 WouldBlock 이면 **연결조차 없었다**.

  기법 C (연결이 거부되는 주소)
    Agent crate 테스트는 127.0.0.1:1 을 준다.
    관문이 늦으면 오류가 연결 실패로 바뀐다 — 그 차이가 순서를 드러낸다.

6. 11라운드 뒤 추가된 뮤테이션
--------------------------------
  S1  Agent 관문을 "항상 거부" 로     -> the_report_guard_stays_out_of_a_lane_that_wants_no_reports
  S2  Agent 관문 제거                 -> run_refuses_unsupported_lane_combinations_before_connecting

★ S1 은 **대조 테스트가 없으면 못 잡는다** — "관문이 걸린다" 만 재는 테스트는
  관문을 항상 켜도 전부 통과한다. 그래서 반대 방향 대조를 둔다:
  신고를 안 보내는 lane 에서는 관문이 걸리지 않고 **연결이 실제로 일어난다.**


7. 관문 호출 지점 — 다섯 곳
------------------------------
  Coordinator  run()  ·  run_from_args()  ·  multi_agent::run_multi_agent()
  Agent        run()  ·  multi_agent::run_multi_agent_session()

★ 관문은 `NeighborReportLane` 을 **인자로 받는다**(11라운드 우회 조사).
  전에는 `config.multi_agent` 를 읽어 판정했는데, `run_multi_agent()` 는
  **그 함수 자체가 그 lane** 이라 플래그를 끄고 부르면 통과했다.
  이제 lane 진입점은 자기 lane 을 명시하고, 아직 분기하지 않은 자리만
  `lane_from_config()` 로 고른다.

★ 거부 대상:
    multi-agent lane                      (수신/송신 루프 없음)
    resume 경로                            (그보다 먼저 반환)
    --send-grant-twice                     (ACK 직후 끝낸다)
    --disconnect-after-ack                 (ACK 직후 끝낸다)
    --drop-connection-after-ack-once       (max_connections > 1 이고 첫
                                            연결일 때만 끝낸다 — 그래도
                                            **보장할 수 없으면** 안 받는다)


8. 오류 종류를 원인에 맞춘다
-------------------------------
  kind=storage       저장소 문제(비영속 · 경로 부재)
  STARTUP_REFUSED    구성 충돌(lane · ACK 조기 종료 플래그)

★ 전에는 lane 충돌도 `kind=storage` 로 찍었고 **테스트가 그 잘못된 분류를
  고정**하고 있었다(11라운드 서술 감사).

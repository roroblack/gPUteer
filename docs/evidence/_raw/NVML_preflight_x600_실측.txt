=== 왜 쟀나 ===

`crates/runtime-nvml/src/preflight.rs` 의 테스트 32건은 **전부 합성
관측값**으로 돈다. 순수 판정 로직은 그것으로 충분히 재지만,
`check_gpu_requirements_now()` 가 **진짜 NVML 을 제대로 읽는지는
아무것도 증명하지 않는다** — 그 함수만 통째로 망가져 있어도 32건이
전부 초록이다.

개발 기계에는 NVIDIA GPU 가 없다(Intel Iris Xe). 그래서 x600 에서 쟀다.

=== 먼저: 기존 테스트를 x600 에서도 돌렸다 ===

  cargo test -p gputeer-runtime-nvml
    -> 32 passed / 0 failed

  cargo test -p gputeer-runtime-nvml -- --ignored
    -> 0 passed / 32 filtered out

★ 두 번째 줄이 요점이다. **실물 NVML 을 부르는 테스트가 0개다.**
  32건이 GPU 있는 기계에서 통과했다는 것은 "합성 판정이 플랫폼과
  무관하다" 는 뜻일 뿐, NVML 연결을 증명하지 않는다.

=== 그래서 프로브를 만들었다 ===

`crates/runtime-nvml/src/bin/preflight_probe.rs`

  1  실제로 관측되는가
  2  지금 사실에 맞는 요구는 통과하는가
  3  틀린 요구 셋은 각각 거부하는가   <- ★ 이게 없으면 2는 뜻이 없다
                                        "항상 통과" 구현도 2를 통과한다

=== 실측 출력 (그대로) ===

PREFLIGHT_PROBE stage=observe ok=true gpu_count=1
  GPU index=0 uuid=GPU-09a269a7-50a8-f5be-2a00-d20a1c281c93
     total=12878610432B free=12524265472B mig=None
PREFLIGHT_PROBE stage=accept ok=true need_free=6262132736B
PREFLIGHT_PROBE stage=reject_absent ok=true
     rejection=SelectedGpuAbsent { uuid: "GPU-00000000-..." }
PREFLIGHT_PROBE stage=reject_vram ok=true
     rejection=InsufficientFreeVram { uuid: "GPU-09a269a7-...",
                free_bytes: 12524265472, required_bytes: 51514441728 }
PREFLIGHT_PROBE stage=reject_count ok=true
     rejection=InsufficientGpuCount { present: 1, required: 2 }
PREFLIGHT_PROBE done
EXIT=0

=== 무엇이 확인됐나 ===

  NVML 을 실제로 읽는다                    O  UUID·총량·여유·MIG 상태
  nvidia-smi 값과 일치한다                 O  12282 MiB ~= 12878610432B
                                              11945 MiB ~= 12524265472B
                                              (MiB 반올림 차이 범위 안)
  맞는 요구는 통과한다                     O
  없는 UUID 를 거부한다                    O  SelectedGpuAbsent
  과한 VRAM 요구를 거부한다                O  InsufficientFreeVram
                                              (실제 여유·요구 값을 둘 다 보고)
  있는 것보다 많은 개수를 거부한다          O  InsufficientGpuCount

=== 확인되지 **않은** 것 ===

★ **여러 장 요구는 못 쟀다.** 이 기계에 GPU 가 한 장뿐이라
  `required_gpu_count >= 2` 의 성공 경로가 안 돈다. 거부 경로만 봤다.

★ **MIG 켜진 장치 거부는 못 쟀다.** 이 카드는 MIG 를 지원하지 않아
  `mig=None` 이다. 합성 테스트로만 확인돼 있다.

★ **NVML 실패 경로는 못 쟀다.** NVML 이 정상이라 `ObservationUnavailable`
  이 실제로 어떻게 나오는지 안 봤다. 합성 테스트로만 있다.

★ **한 번 쟀다.** 반복·부하 상황은 안 봤다. TOCTOU(통과 뒤 다른
  프로세스가 VRAM 을 먹는 것)는 이 계층이 원래 못 막는다.

★ **Agent 에 배선 안 됐다.** `crates/agent/Cargo.toml` 에
  `runtime-nvml` 의존이 없다 — 이 확인은 아직 실행 경로에서 안 불린다.

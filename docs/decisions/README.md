# decisions/ — ADR

**왜 그 결정을 내렸고 왜 바꿨는가**를 남긴다. 코드 주석으로는 "왜"가 사라진다.

## 규칙

- 파일명 `ADR-NNN_<제목>.md`. **갱신 시 새 파일을 만들지 않고 같은 번호를 고친다.**
- 문서 안에 개정 이력을 남긴다.
- 폐기된 ADR 을 삭제하지 않는다. 상태를 `폐기` 또는 `대체됨` 으로 바꾼다.

## 기준선에서 이관된 ADR

기준선 계획서 §38 에 ADR-001~025 가 있다. **구현 과정에서 바뀐 것만** 이 폴더에 개별 파일로 만든다.
바뀌지 않은 것은 기준선을 그대로 참조한다. 복제하지 않는다.

★ **P0 스파이크가 실패하면 반드시 여기에 ADR 을 남긴다** (`RULE.md` §8-4).
계획서만 조용히 고치는 것을 금지한다.

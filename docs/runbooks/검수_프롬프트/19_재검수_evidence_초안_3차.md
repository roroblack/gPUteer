# 물을 것 — 세 가지

1. **16 의 지적이 본문에서 닫혔나.** 지적마다 대조하라.

2. **본문 안에서 서로 충돌하는 문장이 남았나.** 세 번 고친 문서라 한쪽만
   고쳐진 곳이 있기 쉽다 — claim · raw_output · negative_tests · limitations ·
   decision · 본문을 서로 대조하라.

3. **evidence 로 옮겨도 되나.** 안 되면 무엇이 남았나 — 문장 문제인지, 측정이
   더 필요한지 구분해 적어라.

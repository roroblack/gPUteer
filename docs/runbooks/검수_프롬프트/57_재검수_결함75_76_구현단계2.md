물을 것:
1. 75 · 76 이 닫혔나. 새 테스트를 지워도 통과하는 판별 공백이 남았나(예: sig_input 대조가 domain 오류를 잡나).
2. ExitObserved 매핑이 사실대로인가 — Windows `wait()` 성공 뒤 `exit_code()` 실패, 메모리 관측 실패, Linux 신호 종료 각각이
   보고에서 어떻게 보이는지. 종료를 관측하지 못한 경우를 NoCode 로 잘못 보내는 경로가 있나(WaitFailed 는 여전히 오류다).
3. Agent 가 v2 로 보내면서 깨지는 소비 경로가 있나 — 옛 Coordinator(수신 상한 1) 조합, selftest, 저장소 재조회, 예약 해제.
4. 산출물 JSON · 출력 줄 형식 변경(exit_code=none · peak_commit_bytes=unknown · null)이 다른 테스트나 문서의 약속을 깨나.
5. 리눅스를 실행하지 않았다고 적었다 — 그 한계 서술이 정확한가, 넘겨짚은 곳이 있나.
6. 이번 단계가 하지 않은 것(산출물 확정 실패 보고 ⑲ · Hello 먼저 · RENEW/REPORT 세션 · outbox · D1)을 했다고 적은 문장이 있나.

동의가 아니라 **반박**을 원한다. 결함 ⑱ 을 설계 A 로 고쳤다 — 사용자가 "A 먼저, 목표는 B+E" 로 정했다.

# 물을 것

1. **ACK 가 정말 실행 전에 가나** — 모든 경로에서. 워크로드 없는 Grant · NotOptedIn · 관문 거부 · 기동 실패 ·
   산출물 처리 실패 각각에서 ACK 가 몇 번, 언제 가는지. 한 연결에서 두 번 가는 경로가 있나.
2. **관문을 옮기면서 빠진 것이 있나** — 전에 run_and_capture_workload 안에서 걸리던 거부가 지금도 같은 메시지 ·
   같은 순서(시작 마커 · 작업 디렉터리 정리 · 소유자 패널 등록)로 걸리나. 작업 디렉터리가 남는 경로가 생겼나.
3. **PostAckWait 가 맞나** — 첫 읽기가 무엇이든 한 번만 늘어나고 되돌아가나. Manifest 가 있는데 첫 읽기 전에 끝나는
   경로(분기 · early return)에서 문제가 없나. Lease 만료 기준 시각(Coordinator 시계)의 한계. 규범
   (`docs/protocol/state-machines.md` §3 STALE · §5 grace)과 어긋나는 문장이 코드 주석이나 문서에 있나.
4. **재접속 억제가 맞나** — 워크로드를 띄운 연결에서만 억제하나. 억제 때문에 원래 재접속해야 하는 경우(DoD-35 의
   drop-after-ack 시나리오)가 깨지나.
5. **테스트가 공허하지 않나** — P1~P3 · N1~N3 각각이 고친 것을 되돌리면 실패하는지(뮤테이션 결과와 대조),
   시간 경계(N2 의 15초 · 28초, P1 의 10초)가 흔들릴 여지.
6. 같은 부류(관측을 원인 · 필연 · 보편으로 넓히는 문장, 한계를 실제보다 넓거나 좁게 적는 문장)가 문서 · 주석에 있나.

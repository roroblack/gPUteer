# 물을 것 — 둘

1. **44 의 지적이 닫혔나.** 새 문장이 구현(`create_exclusive_temp_with_seq` 의 반복 · 오류 분기)과 맞나 —
   AlreadyExists 가 아닌 오류에서의 동작까지 포함해서.
2. 위 범위에서 같은 부류(관측을 원인 · 필연 · 보편으로 넓히는 문장, 한계를 실제보다 넓거나 좁게 적는 문장)가
   또 있나. 범위 밖에서 보면 "범위 밖 관찰" 로 따로 적어라.

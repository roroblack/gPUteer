# contracts/ — 누가 무엇을 구현·검증하는가

## ★ 이 폴더가 하지 않는 것

**`proto/` 와 `docs/protocol/` 을 복제하지 않는다.**

```text
금지   필드 목록을 Markdown 으로 옮겨 적기
금지   상태 전이표를 두 곳에 두기
금지   서명 알고리즘을 다시 설명하기
```

복제하면 반드시 drift 가 생기고, **어느 쪽이 진짜인지 알 수 없게 된다.**
이것이 A-COP 체계를 이식하면서 의도적으로 바꾼 부분이다.

## 이 폴더가 담는 것

```text
소유권      어느 스트림이 어느 디렉터리를 소유하는가
변경 절차   공용 파일을 바꾸려면 무엇을 거쳐야 하는가
테스트 위치 이 계약을 강제하는 테스트가 어디 있는가
원본 링크   실제 정의는 어디에 있는가
```

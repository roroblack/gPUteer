# 증거 digest 를 체크아웃 줄바꿈과 무관하게

> **작성** 2026-09-17 05:13 · **성격** 실행계획(한 조각) · **결함** `docs/reports/debugs/2026-09-17_0513_증거_digest_가_체크아웃_줄바꿈에_따라_갈린다.md` · **브랜치** `fix/evidence-digest-eol`

## 목표

`scripts/verify_evidence.py` 가 **어느 체크아웃에서도 같은 판정**을 내게 한다 — 변조 탐지를 줄이지 않고.

## 선택지와 판단 (실측은 결함 리포트 3)

```text
A git blob digest 로 대조        커밋 전 새 원문 · 작업 트리 변조를 못 본다 — 탐지가 줄어든다. git 이 없는 곳에서 못 돈다
B LF 정규화 내용으로 digest      기존 기록 72건과 그대로 맞는다(기록이 LF blob 이다). 체크아웃과 무관하다.
                                 잃는 것 — 줄바꿈만 바꾼 변경을 digest 로 못 잡는다(외로운 CR 은 내용으로 잡는다)
C .gitattributes(-text · eol=lf) 이미 CRLF 로 체크아웃된 작업 트리는 다시 체크아웃하기 전까지 그대로 어긋난다. 섞인 줄바꿈으로
                                 기록된 4건과 CRLF 로 기록된 유예 목록 digest 는 어느 체크아웃에서도 재현되지 않는다
```

**B 로 한다.** 4건 · 유예 목록은 섞인/CRLF 바이트로 기록돼 새 정의로 다시 적는다 — 근거는 "메인 체크아웃의 원본 바이트 digest = 옛 기록 ·
LF 정규화 = 커밋된 blob" 실측(내용 변경이 아니다).

## 단계

1. 결함 기록(고치기 전)
2. `lf_normalized` · `sha256_file` · `load_grandfathered` · GRANDFATHER_DIGEST

## 하지 않는 것

- 다른 검사(receipt `파일:줄` 인용 · negative test 이름 찾기)의 줄바꿈 처리 — 텍스트로 읽어 이미 무관하다(이번에 재지 않았다)

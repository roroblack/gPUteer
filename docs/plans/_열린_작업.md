## D. 실제 Job 실행 — 조각 목록

첫 조각(검증된 Manifest -> 실행 지시)은 끝났다. 남은 것:

```text
Coordinator 가 Grant 에 Manifest 를 싣는다        A 항목
Agent 가 nested Manifest 를 독립 검증한다          A 항목
entrypoint 프로세스 실행                          runtime-windows 에 도구는 있다
                                                  (create_constrained_child)
NVML 로 실제 GPU 확인                              DoD-55 는 계산만 분리했다
격리를 실제 자식 프로세스에 적용                    Windows: Job Object 있음 / Linux: cgroup 미착수
체크포인트 데이터 파일 쓰기와 manifest 확정
AttemptReport 를 wire 로 전송                      저장소는 있고 전송이 없다
Job/Attempt 상태 전이 구현                         표만 있고 코드 0
```

★ **상태 전이는 마지막이다.** `state-machines.md` 표에 없는 전이를
구현하지 않는다(`CLAUDE.md` §2). 앞의 조각들이 표의 guard 를 만족시킬
수 있게 된 뒤에 전이를 붙인다.

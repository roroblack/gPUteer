```text
v17 §4   STOP_CONFIRMED 는 소유자 해제 명령이 §4 증거를 확인한 뒤에만 만든다

         ★ 받아들인 한계 그대로(결정 D · b11 ②): 부재는 "**지금 멈췄다**" 의 증거지 "안 돌았다" 의 증거가 아니다 — 자동 STOP 뒤의 Job 처리는 v17 §3 그대로
```

## 2. 대체 통지 "우편함" — ★ 사용자 결정이 필요하다 (p1 ② · p2 ① ②)

v1 은 "장애 이어받기의 Lease 폐기 + 다음 갱신의 서명된 REVOKED" 로 충분하다고 적었다. **틀렸다** — 소유자가 PURE 작업에 "계속 돌리기" 를 고르고 끊긴 채 Lease 가
끝나면, 갱신 함수는 연결 **전에** 스스로 만료(LOCAL_EXPIRED)를 보고 갱신 스레드가 끝난다(agent/lib.rs:2426 · :2783). 작업은 계속 돌고(owner_panel.rs:588), 재기동도
아니라 원장의 ACTIVE 복구도 닿지 않는다. 다시 연결돼도 "그 시도는 넘어갔다" 를 들을 길이 없다 — 결정 D 1번이 바로 이것을 막는다.

```text
결정 D 1번   Coordinator 가 시도를 넘길 때 옛 시도에 대한 **서명된 통지를 영속** · 옛 노드는 다시 붙으면 **새 작업을 받기 전에** 통지를 처리

선택 A  결정 D 그대로 — 진짜 우편함
        새 서명 메시지(옛 시도 신원 · fence · 대체한 시도 · 사유) · Coordinator 표(추가 전용 · 넘길 때 같은 커밋에 서명 바이트까지 저장) · 노드가 묻는 세션
        (Hello 다음 "내 앞으로 온 것" — 새 세션 종류) · 노드의 수신 확인 · 처리 순서(우편함을 비우기 전에는 Grant 를 받지 않는다) · 계약 변경 1건(새 메시지 · 새 세션)
        얻는 것  통지가 저장소 · 발급자와 무관하게 **바이트로** 남는다 · 수신 확인으로 "전해졌다" 를 안다 · 재기동한 노드도 받는다
        잃는 것  새 메시지 · 새 표 · 새 세션 · 계약 검수 한 바퀴 — 조각 하나가 더 크다
선택 B  결정 D 1번을 "영속된 폐기 기록을 노드가 끝까지 묻는다" 로 개정
        Lease 폐기 기록(failover 가 같은 커밋에 revoked_at)이 영속 사실이고, 노드의 갱신 스레드가 그 시도가 끝날 때까지 만료 뒤에도 묻는다 —
        Coordinator 는 폐기된 Lease 에 만료와 상관없이 서명된 REVOKED, 낮은 fence 에는 SUPERSEDED 로 답한다(RENEW 세션 lib.rs:2646~ — p2 ② 확인)
        조건(p2 ②): Agent 의 연결 전 만료 검사(lib.rs:2427)를 **묻기에 한해** 건너뛴다 · 폐기 전 만료 오류는 다시 묻는다 · 시도가 실제로 끝날 때까지 ·
        **정지 여유 0 이어도** 서명된 거부면 멈춘다(지금은 여유 0 이면 정지 요청을 안 한다 — lib.rs:2792 · 이 조각에서 고친다)
        얻는 것  새 메시지 · 표 · 세션 없음 — 조각이 작고 계약 변경이 없다
        잃는 것  서명 통지가 **응답할 때** 만들어진다(바이트로 저장되지 않는다) · 수신 확인이 없다 · Coordinator 가 다른 Lease 저장소로 재시작하거나 발급자 ID 가
                 바뀌면 옛 시도는 서명된 거부를 듣지 못한다(Lease 를 모른다는 오류만) · 실행 중 갱신이 꺼진 lane 은 묻지 않는다(풀 lane 은 갱신 필수라 해당 없음)
                 · 재기동한 노드는 이 길이 아니라 §1 자동 증거가 맡는다
권장     A — 결정 D 의 문구가 정확히 이것이고(사용자 제안), B 의 잃는 것 셋(저장소 교체 · 발급자 변경 · 수신 확인 없음)이 "사람 없이 풀린다" 를 깎는다.
★ 사용자 결정(2026-10-02) — **A**("1로해"). 상황 설명(소유자 "계속 돌리기" · 끊김 · 다른 노드로 넘어감 · 재연결) 뒤 두 선택지의 얻고 잃는 것을 보고 골랐다
         다만 A 를 하기 전에도 **B 의 Agent 쪽 고침(정지 여유 0 에서도 서명된 거부면 멈춤)** 은 지금 기능의 빈틈이라 먼저 넣는다
```

- 상태: 구현·검증 완료

## 범위

`CoordinatorLeaseStore::get_or_issue()`에 호출 시각을 전달하고, identity 충돌과
durable revoke 확인 뒤 저장된 `expires_at_unix_ms`가 현재 시각과 같거나 과거이면
`LeaseStoreError::Expired`를 반환한다. Coordinator는 기존 raw handshake 오류
전파 경로로 명시적으로 종료하며, 새 Grant나 proto/signed outcome은 만들지 않는다.

저장소 단위 테스트는 만료된 기존 레코드의 거부·비변경과 아직 유효한 레코드의
정상 복원을 확인한다. `coordinator-agent-selftest` 시나리오 36은 250ms TTL로
첫 ACK를 완료한 뒤 400ms 실제 벽시계 sleep을 수행하고, 완전히 새 프로세스 쌍이
같은 `--lease-db`로 재접속할 때 `Expired` 거부와 Grant 미전송을 확인한다.

## 제외

- 만료 Lease 자동 갱신·자동 재발급 정책
- proto, signed outcome, Agent 자동 재접속 루프 및 새 외부 크레이트
- evidence/history/CLAUDE 문서 수정, commit/push

# 2026-08-19_1814_lease_재접속_최소_조각_v1

- **기준선:** `docs/plans/2026-08-19_1725_lease_재발급_정책_superseded_v1.md` 및
  오늘 완료된 Coordinator 영속 Lease 저장소·durable FenceWatermark 조각.
- **대상 단계:** v0.1
- **상태:** 구현·selftest·뮤테이션 검증 완료. 독립 검수/evidence 작성은 이
  작업 범위에 포함하지 않는다.

## 목표

연결 단절 뒤 기존 프로세스 쌍을 재사용하지 않고, 새 Coordinator/Agent
프로세스 쌍이 동일한 `--lease-db`와 `--fence-db`를 열어 active Lease의
identity·fence epoch·시각을 복원하고 기존 `ExecutionGrant`/`AgentGrantAck`
handshake를 성공시키는 최소 경로를 증명한다.

## 핵심 결정

- **proto 변경 없음:** 새 메시지·필드·frame type을 추가하지 않는다. 새
  프로세스의 첫 교환도 기존 Grant/ACK를 그대로 사용한다.
- Coordinator에 테스트 전용 `--disconnect-after-ack true`를 추가한다.
  ACK 검증 직후 정상적으로 연결을 닫고, Agent는 기존 오류 전파로 종료한다.
  자동 재접속은 만들지 않는다.
- 새 두 번째 프로세스 쌍은 첫 쌍과 같은 Lease/Fence DB를 사용한다.
  Coordinator CLI에는 의도적으로 `--fence-epoch 3`을 주지만,
  `CoordinatorLeaseStore::get_or_issue()`가 저장된 Lease(epoch 5)를
  우선해 Grant/ACK가 성공해야 한다.
- 같은 `lease_id`를 다른 `holder_node_id`로 주장하는 재접속은
  Coordinator 발급 단계에서 거부한다. 이 검사는 기존 코드의
  `check_identity_conflict()`와 `conflicting_holder_node_id_is_rejected_without_overwrite`
  단위 테스트에 이미 존재하므로 저장소 로직은 변경하지 않고, 별도
  프로세스 selftest 시나리오로 호출부를 추가 검증한다.

## 범위

### In

- 의도적 ACK 직후 연결 단절 주입과 Agent의 오류 종료 확인.
- 같은 `--lease-db`/`--fence-db`를 사용하는 새 Coordinator/Agent 프로세스
  쌍의 active Lease Grant/ACK 복원 확인.
- 저장된 epoch가 잘못된 새 Coordinator CLI epoch보다 우선하는지 확인.
- 같은 Lease identity에 다른 holder를 사용한 Coordinator 거부 negative test.
- `coordinator-agent-selftest` 시나리오 33·34 및 기존 시나리오 회귀 검증.

### Out

- Agent 자동 재접속 loop, retry/backoff/jitter.
- `ResumeLeaseRequest`, reconnect token, session ID 등 새 프로토콜 계약.
- 같은 Coordinator의 다중 연결 수락 구조, 다중 Agent 경쟁, HA, TLS.
- 만료된 Lease의 재발급/복원 정책(선택 시나리오 35는 다음 조각으로 명시적
  이월).
- revoke 상태의 재접속 보존. 현재 `revoked`는 Agent 메모리 상태이고
  `CoordinatorLeaseStore`에는 revoke 필드가 없으므로, 프로세스 단절 뒤
  새 Agent가 Lease를 다시 받을 수 있는 DoD-22 한계를 그대로 재확인한다.

## `RenewLeaseRequest` 재사용을 미루는 이유

새 연결의 첫 메시지로 `RenewLeaseRequest`를 보내면 재접속과 정상 갱신을
구분할 수 없다. 또한 selftest의 결정적 nonce 유도는 같은 Lease에서
재사용될 수 있어 replay 판정과 충돌할 위험이 있다. 이번 조각은 이미
인증된 Grant/ACK 경로만 재사용하고, 명시적 resume 계약과 자동 재접속은
후속 조각으로 미룬다.

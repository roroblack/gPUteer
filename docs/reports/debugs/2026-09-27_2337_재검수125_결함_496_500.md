## 조치

갈라진 세션의 490 · 491 · 495 커밋(`338e0db`) 위로 옮겨 고쳤다(그쪽 start 분기는 멈춤 확인 → 로그 → 둘 다 확인됐을 때만 삭제라 496 규칙과 맞는다).

| # | 무엇을 바꿨나 | 확인 |
|---|---|---|
| 496 | 종료를 못 본 경로에서 `logs_complete = stopped && 로그 받음`. 멈춤을 확인하지 못했으면 받은 로그를 "지금까지의 로그만" 으로 적는다. start 분기의 멈춤 미확인 결과도 `logs_complete: false` | `an_unconfirmed_stop_never_removes_the_container` 에 `logs_complete: false` 단언. 뮤테이션(`stopped &&` 제거)을 잡았다 |

★ 시험이 잡지 **않는** 것 — lib 의 `*keep_run_dir = outcome.container_needs_human` 한 줄(lib 단위 시험은 컨테이너 경로를 돌리지 않는다)과 agent-loop 의
`return Err` 자체(단위 시험은 판정 함수만 본다). 둘 다 코드를 읽어 확인했다.
★ 남는 것 — 표식을 **만들기 전에** 죽는 경우와, 표식을 못 써 멈춘 뒤 폴더가 다시 쓸 수 있게 된 상태로 재기동하는 경우는 관문이 못 막는다. 그때도 작업 폴더는
남고 남은 컨테이너 정리는 멈춤 · 로그 건지기를 확인한 뒤에만 지운다(492). 런북 "표식이 닿지 않는 곳" 에 적었다.

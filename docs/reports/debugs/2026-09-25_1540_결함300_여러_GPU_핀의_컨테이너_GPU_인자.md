# 2026-09-25 15:40 — 결함 300: GPU 를 여럿 고정한 노드의 컨테이너 GPU 인자가 런타임 문법에 맞지 않는다

> fork(`fork-install-gpu`) 작업 중 코드를 읽다 찾았다. 결함 번호 300~399 는 fork 몫이다(main 과 합의).

## 1. 위치

```text
crates/agent/src/container.rs  create_args() — `if let Some(pin) = execution.gpu_pin` 가지
crates/agent/src/lib.rs        parse_gpu_pin() — "0,1" 처럼 쉼표로 여럿을 받는다
```

## 2. 재현

코드 읽기로 찾았다. **실제 런타임으로 재현하지 않았다**(개발 기계에 docker · podman 이 없다).

```text
Agent   --gpu-pin 0,1 --container-runtime ... --container-gpu true
podman  --device=nvidia.com/gpu=0,1          CDI 장치 이름 "0,1" 은 없다 — create 가 실패한다(예상)
docker  --gpus device=0,1                    docker CLI 는 --gpus 값을 CSV 로 읽는다 → 필드 "device=0" · "1".
                                             "1" 은 개수(count)로 읽혀 DeviceIDs 와 Count 가 같이 선다 — 거부된다(예상)
```

★ 두 줄의 "실패한다" 는 **예상**이다(각 런타임의 문서 · 소스를 읽은 판단). 전역 규칙 §7 — 잰 값과 섞지 않는다.

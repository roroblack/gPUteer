★ 남는 것
- 관측을 켰다가 불일치가 난 노드는 **관측을 켠 Agent 의 맞는 관측**으로만 풀린다 — 관측을 끄면 영영 빠진다(운영자가 지우는 명령은 아직 없다).
- `--register`(Linux root · systemd)와 `-Register`(작업 스케줄러)는 이번에도 실제로 돌리지 않았다 — 시스템 설정을 바꾸는 일이다.
- Windows ACL 은 개발 기계 한 대에서, Administrators 그룹이지만 권한 상승하지 않은(UAC 로 거부 전용) 셸 하나로 쟀다 — 상승한 셸 · 다른 계정에서 여는 시도는 재지 않았다.

| # | 심각도 | 결함 | 반례 요지 |
|---|---|---|---|
| 506 | 높음 | 소유자 화면의 정지(`ContainerStopper::stop`)는 `kill` 이 0 이면 멈춤을 확인하지 않고 성공이다(502 는 `stop_and_confirm` 만 고쳤다). 런북 · 결함 문서 501~505 의 "kill 뒤 inspect 한다" · "`ContainerStopper::stop` 도 고쳤다" 가 코드보다 강하다 | kill 이 0 인데 컨테이너가 계속 돔 → 패널이 `owner_stopped` 를 적음 → GPU 는 계속 묶임 → 작업이 나중에 정상 종료해도 보고가 `INTERRUPTED` → Coordinator 가 `PAUSED` 로 재배치 → 끝난 작업이 다시 돌 수 있다 |
| 507 | 높음 | 런북의 `--register` 절차가 **사용자 체크아웃**을 `sudo cp -r` 로 root 사본으로 만든 뒤 실행한다. 소유권 검사(`root_owned_chain`)는 복사 뒤의 소유자만 보고 바이트의 출처는 보지 못한다 | 같은 계정으로 돈 S0 작업이 체크아웃의 `install-node.sh` 를 바꿈 → 운영자가 문서대로 `sudo cp -r` → 변조본이 root 소유 → `sudo sh` 가 root 로 실행(검사 전에 공격 코드가 돈다) — 계정 권한 안의 변조가 root 실행으로 올라간다 |
| 508 | 중간 | 런북의 "kill 뒤 약 2초까지 다시 본다" 는 재시도 사이 대기만 센 값이다. 명령마다 120초 시한(`SHORT_TIMEOUT`)이라 런타임이 응답하지 않으면 사전 inspect 1 · kill 1 · inspect 10 으로 약 24분 걸린다 | 런타임이 모든 호출에 응답하지 않음 → 멈춤 확인 하나가 약 24분(자동 파괴 · 성공 확정은 없지만 운영자가 기대할 시한이 틀렸다) |

## 조치

| # | 무엇을 바꿨나 | 확인 |
|---|---|---|
| 506 | `ContainerStopper::stop` 이 `kill` 의 0 뒤에 `confirm_stopped`(`stop_and_confirm` 과 같은 확인 — `inspect_running` 이 "돌지 않는다" · "없다" 일 때만)를 거친다. 확인하지 못하면 `KILL_UNCONFIRMED` 로 실패를 돌려준다 — 패널은 `owner_stopped` 를 적지 않는다. ★ 결함 문서 501~505 의 "`ContainerStopper::stop` 의 이미 끝났다 판정도 `inspect_running` 으로 본다" 는 kill **실패** 분기만 뜻했는데, 성공 분기까지 고친 것으로 읽혔다 — 이번에 성공 분기를 고쳤다 | 새 시험 `the_owner_stop_is_not_reported_until_the_container_stopped`(가짜 런타임 `kill-noop` → `stop()` 이 `KILL_UNCONFIRMED` · 실제로 멈춘 뒤 실행이 137 을 관측). 뮤테이션(성공 분기의 확인을 빼고 `Ok`)을 잡았다 |
| 507 | 런북의 `--register` 절차를 바꿨다 — 사용자 체크아웃을 `sudo cp` 하지 않고, root 가 **직접** 저장소에서 받아 운영자가 저장소 밖의 경로로 알려 준 커밋 id 와 대조한 뒤 root 소유 사본을 만든다(비공개 저장소면 운영자가 건넨 묶음을 `sha256sum` 대조). 설치기의 `INSTALLER_NOT_ROOT_OWNED` 안내도 옛 복사 명령 대신 이 절차를 가리킨다 | `sh -n` · `check_docs.py`. ★ 코드로 막을 수 없는 문제다 — 바뀐 스크립트는 자기 검사보다 먼저 돈다. 보증은 받기 · 대조 **절차**가 준다고 런북에 적었다 |
| 508 | 멈춤 확인 조회(`inspect_running`)의 시한을 15초(`CONFIRM_TIMEOUT`)로 줄이고, 런타임이 답하지 않으면 더 묻지 않고 곧바로 "모른다" 로 끝낸다. 런북에 최악 시간(사전 조회 15초 + kill 120초 + 확인 조회 15초 = 약 2분 30초)과 그 앞의 종료 관측 시간은 따로라는 것을 적었다 | 시험 없음 — 시한을 재는 시험은 두지 않았다(가짜 런타임에 멈춤을 흉내 내면 시험이 분 단위로 길어진다). 코드 대조로 확인했다 |

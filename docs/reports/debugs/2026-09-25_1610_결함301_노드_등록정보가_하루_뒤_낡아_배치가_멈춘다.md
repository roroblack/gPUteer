## 2. 재현

코드 읽기로 찾았다. `update_inventory` · `import_bootstrap` 을 `crates` 전체에서 찾았고(`grep -rn`), 운영 경로에서
부르는 곳은 `import_inventory.rs:101` 하나다(나머지는 각 저장소의 `#[cfg(test)]` 안). Agent 의 인사(Hello)는 생존 관측
(`node_liveness_store`)만 갱신하고 inventory 의 `observed_at_unix_ms` 는 바꾸지 않는다.
이 방법이 놓칠 수 있는 것: 다른 이름으로 inventory 행을 직접 UPDATE 하는 SQL — `observed_at_unix_ms =` 로도 찾았고
`inventory_store.rs:359`(같은 upsert) 외에 없었다.

실측은 설치 스크립트 시험에서 한다(§3).

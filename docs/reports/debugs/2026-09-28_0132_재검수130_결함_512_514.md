| 512 | 높음 | 사건 해제 명령(`gputeer container-incidents`)이 `--checkpoint-root` 를 **실제 경로로 풀지 않고** 형제 폴더를 계산한다. Agent 는 기동 때 루트를 `canonicalize` 한 뒤(`lib.rs` 632행) 표식 폴더를 정한다(655행). `--clear-all` 은 그 폴더의 모든 항목을 지운다 | `C:\alias\cp` 가 `D:\real\cp` 를 가리키는 junction · 설정에 별칭 → Agent 는 `D:\real\container-incidents` 에 기록 → 운영자가 `--checkpoint-root C:\alias\cp --clear-all` → CLI 는 `C:\alias\container-incidents` 를 봄 → 없으면 0건 성공 · 실제 표식은 남아 기동 거부가 계속 / 거기 다른 파일이 있으면 그것을 지움 |

## 조치(계획)

```text
475  start · rm 둘 다 실패하면 정지 손잡이를 **넘긴 뒤** NotObserved 를 돌려준다(owner 가 kill 로 멈출 수 있다). Agent 는 종료를 못 본 경우(EXEC_FAILED:WAIT)
     패널에서 빼지 않는다(OWNER_PANEL_KEPT) — 소유자가 정지를 누르면 kill 이 가고, 이미 없으면 ALREADY_EXITED 로 보인다
476  node-doctor 는 점검 컨테이너가 NotObserved 면 점검 폴더를 지우지 않고, 컨테이너 이름과 치우는 명령을 FAIL 에 적는다
477  Windows 는 `[System.IO.File]::Replace`(ReplaceFile — 원자적 교체)로 바꿔 넣는다. refresh 는 잠근 뒤 `join-*.json.tmp` 를 본다 — 활성 사본이 없으면 되살리고
     (RECOVERED), 있으면 낡은 임시 파일을 지운다(sh · ps1 둘 다)
478  sh 도 활성 사본의 revision 을 못 읽으면 멈춘다(백업에서 되살리라고 알린다). 후보만 건너뛴다
479  refresh 도 환경 파일을 읽기 **전에** 잠근다. admit 은 환경 파일을 임시 파일에 쓰고 바꿔 넣는다(sh: 권한을 보존한 사본 → mv · ps1: File.Replace)
```

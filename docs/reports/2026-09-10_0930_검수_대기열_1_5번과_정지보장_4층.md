## 2. A — 실측 넷

### A-1. WSL2 에 GPU 가 보인다 (문서가 거짓이었다)
`CLAUDE.md` 가 2026-08-30 부터 "GPU 는 WSL 에 노출되지 않는다" 고 적어
뒀는데 **거짓이었다.** `nvidia-smi` 가 RTX 4070 SUPER 를 보고하고
`/dev/dxg` 가 열려 있으며, **libcuda 로 컨텍스트를 만들어 1GiB 를 실제로
잡았다.**
- 근거 `docs/evidence/_raw/WSL_GPU_MPS_실측_2026-09-08.txt`

  **다시 재는 것만이 검사**라 스크립트를 저장소에 넣었다

### A-2. MPS 는 WSL 에서 확정적으로 불가능하다
두 갈래로 확인했다 — 하나만 보면 "안 깔림" 과 "지원 안 함" 을 구분 못 한다.
```text
(가) 드라이버 번들에 MPS 바이너리가 없다. WSL 은 유저스페이스를 호스트
     Windows 에서 가져오므로 "빠뜨림" 이 아니라 "안 줌" 이다
(나) root 로도 compute mode 를 못 바꾼다 (Insufficient Permissions)
```
-> `GPU_ALLOCATION_MODE_SHARED` 는 여전히 못 쓴다. `ENVIRONMENT-BLOCKED`
   이지 PASS 가 아니다(§4).

### A-3. MPS 없이 VRAM 상한을 거는 수단이 있다 — 단 등급이 낮다
유저스페이스 CUDA 심볼 가로채기로 RTX 4070 SUPER 에서 동시 사용량 상한이
실제로 걸렸다. MIG·MPS·root·드라이버 변경 전부 불필요.

★★ **1차 측정이 틀렸고 독립 검수가 잡았다.** shim 의 `cuMemFree_v2` 가
사용량을 안 줄였고 probe 는 free 를 한 번도 안 불렀다. 잰 것은 "동시
사용량 상한" 이 아니라 **"생애 누적 할당 상한"** 이었다 — 잡았다 풀기를
반복하는 정상 작업을 **막는 게 아니라 죽이는** 것이었다.

★ **대조군을 셋이나 뒀는데 못 잡았다. 셋 다 free 를 안 부르는 같은
경로만 밟았다.** 대조군은 개수가 아니라 **경로가 갈라져야** 뜻이 있다.

- 근거 `docs/evidence/_raw/VRAM_유저스페이스_가로채기_실측_2026-09-08.txt`
- 도구 `scripts/vram_interception_probe/`

### A-4. 운영체제가 강제하는 시한이 두 플랫폼 다 있다
```text
Linux    systemd-run -p RuntimeMaxSec
         띄운 프로세스를 SIGKILL 해도 시한대로 발동. 정지 여유 안에서
         체크포인트를 쓰게 해 주고, 신호를 무시하는 작업도 죽인다
         ★ root 필요. 비-root 는 거부됨
Windows  JOB_OBJECT_LIMIT_JOB_TIME
         작업 개체 손잡이를 **닫은 뒤에도** 커널이 종료시킨다
         ★ 권한 불필요. 단 CPU 시간이라 어림이고 정지 여유가 없다
```
★ 한 번 "Windows 는 답이 없다" 고 결론지었다가 사용자 지적으로 다시 찾아
뒤집었다. **너무 일찍 문을 닫았다**(전역 규칙 §2).

- 근거 `docs/evidence/_raw/운영체제_시한_실측_2026-09-09.txt` ·
  `윈도우_커널_시한_실측_2026-09-09.txt`
- 도구 `scripts/os_deadline_probe/`

## 3. B — 정지 보장 4층 설계

사용자가 순서를 지시했다: **중계 -> 대표 PC -> 각자의 시간 -> 예약.**
층마다 막는 실패가 다르고 아래로 갈수록 조건이 가혹해진다.

★ 1층은 처음에 "중계 프록시로 길목을 잡는다" 였는데 사용자가 "그거 다
어렵다" 고 지적해 **"손이 안 닿게 한다"** 로 전면 수정했다 —
outbox · 짧은 수명 자격증명 · 배치 단계 거르기. 전부 **제출·배치 시점의
판단이지 운영하는 설비가 아니다.**

- 설계 `docs/plans/2026-09-09_0130_정지_보장의_4층_설계.md`

★★ **이 설계는 아직 독립 검수를 못 받았다.** 걸었는데 명령 구성이 틀려
실행조차 안 됐고, 다시 걸려던 참에 쿼터가 끊겼다.
